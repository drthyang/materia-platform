# Reference data stays outside the repo unless its licence allows it

Tests compare against outside references without redistributing them: fixtures generated with spgrep (BSD-3) are committed with attribution; ISO-IR and the ISOTROPY Linux binary (no stated licence) are downloaded in an opt-in CI job and never committed; Bilbao results (CC BY-NC-SA 4.0, incompatible with AGPL-3.0) enter only as published counts written into tests by hand, with their source.

Published nomenclature is not reference data (THY-73, 2026-11-08; ADR 0004). The CDML k-vector names and coefficients that Bilbao's KVEC lists ship in the app, written by hand. The opt-in ISOTROPY oracle checks them against ISOTROPY's k-point list, and its output stays in the CI log. That list is a check, never a source: a name it contradicts is removed from the table, not corrected from it (THY-73 removed three, ADR 0004). Bilbao's programs answer scripts with a bot check, so their values enter tests only as a person hand-types them from a browser, with the page and the date. Irrep numbering tables, ISO-IR's or Bilbao's, stay out unless their authors give permission.
