# Reference data stays outside the repo unless its licence allows it

Tests compare against outside references without redistributing them: fixtures generated with spgrep (BSD-3) are committed with attribution; ISO-IR and the ISOTROPY Linux binary (no stated licence) are downloaded in an opt-in CI job and never committed; Bilbao results (CC BY-NC-SA 4.0, incompatible with AGPL-3.0) enter only as published counts written into tests by hand, with their source.
