# ISODISTORT is MATERIA's single convention system

Every user-facing convention follows ISODISTORT: the translation phase exp(+2πi k·v), mode amplitudes as A_s (over the primitive child cell) and A_p = A_s·√(V_p/V_s), mode-CIF interchange, and child groups reported in ITA standard setting with their (P_H, p_H). Bilbao is used only to cross-check subgroup counts. Supporting both tools' conventions would mean two sets of conversions to test for every output, and users compare modes against ISODISTORT. Without ISO-IR's matrices, MATERIA's order-parameter direction symbols can differ from ISODISTORT's, so tests compare groups, characters, mode counts and amplitudes, never raw matrices.

MATERIA's earlier amplitude normalised over the conventional child cell, which is √f too large for a child with f lattice points per cell; it is converted to A_s and A_p for display, and the refined parameter's unit changes only after the agent validation freeze.
