# The published Mn₃Ga 350 K POWGEN data, and its golden tests in CI

Pull request [#98](https://github.com/drthyang/materia-platform/pull/98),
branch `docs/magnetic-demo-gif` (which contains `data/mn3ga-powgen-350k`), on
`main`, 2026-10-19. The user's published Mn₃Ga 350 K data and refined
structure, committed on 2026-10-12 for a magnetic demo, brought up to date
with `main`. AGENT_REVIEW's larger item 1: "CI runs none of the external
comparisons… Committing small public reference fixtures… would put them in
CI."

## What changed, and why

| Change | What it answers |
| --- | --- |
| **`examples/mn3ga-350k/`**: the POWGEN histogram (PG3_45598, bank 1) and its instrument parameters, the published GSAS-II magnetic structure (C m′c m′), MATERIA's refinement of it, and the structure in its parent group C m c m with no moments (a starting model for a magnetic demo that finds the order from the data) | The data are published; the user committed them so a magnetic demo and the tests could use them |
| **The test data helper reads the committed copy when `data/` has none** (`COMMITTED` in `src/testSupport/data.ts`, for the set's two local names `Mn3Ga_POWGEN_350K` and `350K`). A local copy still comes first | The 350 K golden tests read only the git-ignored `data/` folder, so they skipped in CI and on a fresh clone. They are the one GSAS-II magnetic comparison the suite holds |
| **The single-fit golden test's timeout from 60 s to 180 s** | It takes 17 s here alone; it was set for a local run, and CI runs it beside the other files |
| **The examples README says what uses the files** | It named a "magnetic demo replay" that does not exist; the bundled magnetic demo is the local AWO₄ one |

## Evidence

- `src/testSupport/data.test.ts`: the set is found under both names without
  `data/`, and a set neither local nor committed is still absent. The first
  fails on `main`.
- With the committed copy and no `data/` folder, the tests that were skipping
  now run and pass:
  - `mn3ga350KGolden.test.ts`, the moments refined against the histogram: staged fit wR 8.33 %, golden moments held 8.34 % (17 s);
  - `magneticMultiStartGolden.test.ts`, 21 of 21 seeded starts within 1 % of the best χ², |m₀| = 2.05 and |m₁| = 1.71 μ_B, deterministic (41 s and 48 s);
  - the 350 K CIF tests in `realData.test.ts` and `magneticCif.test.ts`.
- `mn3ga350KDiagnostic.test.ts` still skips. It runs only with `MAG_DIAGNOSTIC=1` (`npm run test:mag-diagnostic`).

## What changes for users

Nothing in the app: `examples/` is not part of the build. The data and the
starting model are in the repository for anyone to load.

## What it means for the validation

Mn₃Ga is a development material, not one of the held-out test cases, and no
eval scenario reads these files. CI now holds the GSAS-II magnetic comparison.

## Not done

- A public magnetic demo on these data (the branch's name): the bundled
  magnetic demo still needs the local AWO₄ data and is not in the public
  build. Building one is a new demo entry and loader. It is not started.
- The other external comparisons (the GSAS-II 600 K and GaNb₄Se₈ sets,
  SHELXL, FullProf, WinGX) still read `data/` only. They need data that can
  be published.
